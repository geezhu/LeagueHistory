# Timeline map backgrounds

Riot Games Data Dragon originals, downloaded 2026-09-08:
- https://ddragon.leagueoflegends.com/cdn/10.18.1/img/map/map11.png
- https://ddragon.leagueoflegends.com/cdn/10.18.1/img/map/map12.png

These are standard Summoner's Rift and Howling Abyss backgrounds, not season-specific map skins.
Coordinate bounds: https://hextechdocs.dev/map-data/
World Y is inverted for screen coordinates. Points outside the documented bounds are omitted rather than clamped onto the border. Unknown maps have no projection. Kill colors use killer participant team, with neutral gray for unknown/environment kills.

Economy chart uses blue total / blue participant count minus red total / red participant count. This is an explicit per-player average difference; WeGame's exact calculation is not verified. Incomplete frames remain gaps.
