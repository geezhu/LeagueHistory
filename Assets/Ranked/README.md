# Ranked emblems

Original League of Legends client assets, owned by Riot Games, distributed by CommunityDragon.
Downloaded 2026-09-08 from:
https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/images/ranked-emblem/

The ten original PNGs are embedded in the application. The UI fits their visible alpha bounds without modifying the files. Unknown/unranked tiers show no emblem.
