# Champion class icons

Original Riot Games client assets, mirrored by CommunityDragon. Downloaded 2026-09-08 without modification.

Source: https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-champ-select/global/default/

Each local `<role>.png` corresponds to `class-icon-<role>.png` in that directory:
fighter, tank, mage, assassin, marksman, support. All six images are 59 × 59 PNGs.

These represent champion classes, not lane positions. Embedded into the executable assembly for offline display.
