# OP.GG 集成需求草稿

记录日期：2026-09-08

状态：基础集成已实现。下方保留早期需求记录；以以下 2026-09-09 实现说明为准。

当前支持峡谷、大乱斗、竞技场、无限火力与极限闪击；排名与详情采用两级布局，提供前进/后退、完整符文树、装备及对局统计。段位按模式记忆。默认跟随选人，并按分配位置或英雄可用位置自动选择分路；手动浏览会暂停跟随。未支持的模式按用户要求回退峡谷攻略，并显示实际查询模式。海克斯独立数据源仍在调查，尚未接入。

请求使用 OP.GG 未文档化接口，已用实际响应样本验证，不视作官方开放 API。轮换模式保留源数据版本；缓存、取消和工具专用符文页写入均有回归检查。

## 本轮交付

- 主导航新增 OP.GG 页面，提供英雄查询、地区/段位/模式/分路筛选及英雄梯队。
- 展示召唤师技能、加点、装备、符文、对局信息；竞技场额外展示强化符文、搭档与名次统计。
- 页面可见时可跟随选人；未锁定、断线及不支持模式不自动套用其他模式。
- 默认手动浏览，不绑定当前房间；模式可选召唤师峡谷、极地大乱斗、斗魂竞技场。切换筛选自动刷新并退出跟随选人，不适用的分路/段位筛选自动隐藏。
- 移除顶部英雄下拉选择，进入页面自动加载中路梯队，点击梯队英雄进入攻略。
- 用户点击应用符文后，创建或更新 `[League] OP.GG ` 前缀的专用页，不覆盖个人页、不自动删除页。
- HTTP 保留 TLS 校验，20 秒超时、可取消、一次短暂重试；128 项缓存，15 分钟过期，支持强制刷新。
- 当前默认全球/翡翠及以上/中路，普通大乱斗选人联动使用全部段位；匹配队列使用明确标注的“排位攻略”。
- 新版程序：`bin/Release/opgg-integration/League.exe`。

### 验证结果与限制

- 2026-09-08 使用本项目 HTTP 客户端在线验证 ranked、aram、arena 攻略及梯队均成功，版本为 16.17。
- 梯队返回 ranked 270 条分路记录、aram 173 个英雄、arena 173 个英雄。
- 测试覆盖三种模式的真实结构样本、缓存隔离/刷新/去重、取消请求、空数据和专用符文页写入策略；符文写入使用模拟 LCU，不修改真实账号。
- `aram-mayhem` 与 `aram_mayhem` 候选模式参数返回 422；队列 2400 明确显示未支持。页面存在不等于目前已确认可用的 JSON 接口。
- 英雄中文名称及图标复用 LOL 客户端资源；资源缺失显示名称/ID 占位，仍可点击梯队英雄查询。
- 自动弹窗、置顶、独立代理设置、装备导入仍作为后续候选，不在本轮启用。

## 目标

在联盟视界内查看英雄梯队与攻略，并可根据当前选人英雄展示对应推荐。通过本地控件展示数据，复用现有英雄、装备和符文资源加载能力。

## 候选功能

### 英雄梯队与查询

- 英雄搜索与梯队列表。
- 按地区、模式、段位和分路筛选。
- 显示梯队、排名、胜率、登场率、禁用率及数据版本。
- 点击英雄进入攻略。

### 英雄攻略

- 推荐召唤师技能组合。
- 技能升级优先级与加点顺序。
- 出门装、鞋子、核心装备和后续装备。
- 多套推荐符文，展示胜率、使用场次和选用率。
- 优势、劣势对局。
- 数据来源、版本和当前筛选条件清晰可见，避免把统计推荐当作固定结论。

### 选人联动

- 从 LCU 读取自己的英雄、分路和当前队列。
- 选定英雄后切换到对应攻略；大乱斗换英雄后更新。
- 相同请求去重；切换英雄或筛选条件后，旧请求不得覆盖新结果。
- 手动浏览入口；自动弹出、窗口置顶是否需要，待确认。

### 应用符文

- 由用户点击应用，调用 LCU 写入所选符文方案。
- 主系、副系、符文和属性碎片完整映射。
- 处理客户端未连接、页面不可编辑、符文页额度不足及写入失败。
- 覆盖当前页还是使用工具专用页，待确认；不直接照搬覆盖当前页的策略。
- 一键导入装备和设置召唤师技能尚未确认，暂不列入首期范围。

### 竞技场扩展

- 强化符文、搭档、平均名次和第一名率。
- 列为后续候选功能，先确认接口数据与模式可用性。

## 模式与数据源待验证

- 萨勒芬妮代码使用 `https://lol-api-champion.op.gg`，本次仅检查本地源码，未验证在线接口现状。
- 梯队路径：`/api/{region}/champions/{mode}?tier=…`。
- 英雄攻略路径：`/api/{region}/champions/{mode}/{championId}/{position}?tier=…`；竞技场不带位置参数。
- 核实可用地区、段位、分路、版本字段以及返回结构。
- 普通大乱斗与海克斯大乱斗必须区分。参考代码没有处理队列 2400，会回落到 ranked，不能照搬。
- 海克斯大乱斗是否有独立数据源、对应模式参数及强化符文推荐，待验证。
- 不支持的模式应明确提示，不静默展示其他模式的数据。
- 默认地区、段位、分路及匹配如何映射排位攻略，待确认。

## 技术与体验要求

- HTTP 请求异步执行，保持 TLS 证书验证，设置超时、取消与适度重试。
- 缓存按地区、模式、段位、英雄和分路区分，并设置过期策略与刷新入口。
- 防止重复请求；资源缓存与攻略数据缓存分离。
- 正确处理空列表、缺失字段、零场次、接口变更与加载失败。
- 提供加载中、无数据、失败重试状态；关闭页面时取消无用工作。
- 是否增加 OP.GG 独立代理设置，待确认。
- 图标与中文名称优先复用本项目资源能力。

## 建议实现顺序（待确认）

## 验收重点

- 不同筛选条件不会串用缓存。
- 快速切换英雄时，最终展示的是最后选中的英雄。
- 无数据、请求失败和断开客户端均不会卡住界面。
- 海克斯大乱斗未接入独立数据时，按后续确认的需求回退峡谷，并明确显示峡谷模式。
- 符文写入只在用户点击后执行，失败有明确反馈。
- 窄窗口下关键信息可读，长列表可滚动。
