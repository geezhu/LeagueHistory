# arammeta · 海克斯大乱斗需求草稿

记录日期：2026-09-09

状态：临时需求记录，尚未开始实现，不纳入本次 OP.GG 提交。

## 目标与定位

为海克斯大乱斗提供类似现有 OP.GG 的“英雄榜 → 英雄详情”体验，使用 arammeta 的独立数据源。明确标注来源“arammeta · 海克斯大乱斗”，不将其统计标为 OP.GG。

保留当前 OP.GG 功能。海克斯数据接入成功后，队列 2400 可使用自身攻略，不再默认回退峡谷。独立导航入口还是统一攻略入口，留待实现前确认。

## 数据来源与已验证情况

- 项目：https://github.com/Lanternko/ARAM-Mayhem-Database
- 网站：https://arammeta.com/
- 榜单聚合 JSON：https://arammeta.com/api/tier-list.json
- 英雄详情：https://arammeta.com/api/champions/{英雄ID}.json
- 榜单接口已实测可读取；英雄详情文件及结构已在仓库确认，接入时还需验证在线详情请求。
- 调查样本为版本 16.17，173 个英雄、209 个增幅条目。这是调查时的快照，不能写死在产品中。
- 这是网站公开的静态 JSON 数据，尚未确认正式的接口兼容性承诺。
- 来源项目通过 LCU 收集对局，发布聚合统计。首版只读取公开聚合数据，不包含上传玩家对局或身份信息的需求。
- 顶层可见 champs、augs、tiers、patch_prefix、ddv、detailBase、detailVersion 等字段。
- 英雄详情可见 bot、sets、items、singleItems、boots、spells、itemClusters、augTypes 等字段；具体含义和推荐排序需核对来源代码，不能仅凭字段名推断。

## 界面需求

### 顶部与导航

- 使用前进、后退语义，在英雄榜和浏览过的英雄详情之间导航。
- 提供刷新与跟随选人开关，显示数据来源和实际版本。
- 返回英雄榜时恢复搜索、筛选、排序和滚动位置。
- 暂无分路、段位筛选的数据依据，不展示这些控件。

### 英雄榜

- 展示头像、名称、梯队、调整后胜率和样本量。
- 支持英雄搜索、职业筛选、数据列排序。
- 点击英雄进入详情。
- 中文名、英雄 ID、图标应与当前项目资源兼容，缺失时提供可读占位。

### 英雄详情摘要

- 展示头像、名称、梯队、调整后胜率、原始胜率和样本量。
- 明确区分 wr 和 rawWr 的统计含义；没有原始值时不能反推或伪造。
- 用问号悬浮提示解释统计口径，正文保持紧凑。

### 强化符文推荐

- 按银色、金色、棱彩分组。
- 显示图标、名称、可换行的说明、推荐程度、样本量及已核实的统计指标。
- 推荐分数、胜率、选取率、提升值需分别标识，不能混为同一百分比。
- 对低样本及缺失值做明确展示，不把缺失值填为 0。
- 可用全部列表随详情页滚动，避免无说明地只截取几个条目。

### 装备推荐

- 展示装备组合、单件装备、鞋子和召唤师技能。
- 复用 OP.GG 紧凑数据行：图标、统计值和样本量对齐。
- 若来源没有对应字段，显示暂无数据或隐藏该区域，不借用普通大乱斗的数据。

### 后续候选：强化组合与英雄搭配

- 强化组合与单个强化分开展示，不混用统计。
- 展示适合搭配的英雄及协同指标。
- 先确认 sets、pairs、lift、score 等字段的含义、排序和样本口径，再接入。
- 不把协同指标当成对线克制胜率。

## 交互与加载

- 默认跟随海克斯选人，检测到英雄变化后加载对应详情。
- 手动搜索、选择英雄或导航后暂停跟随，避免覆盖用户正在看的内容。
- 没有选人会话时可浏览英雄榜；断线不阻塞手动浏览。
- 快速切换时取消过期请求，最终只显示最后一次选择。
- 加载失败提供重试；存在可用缓存时保留内容并标记缓存状态。
- 按来源版本或 detailVersion 管理缓存，避免榜单与详情跨版本混用；缓存时长在实现时确定。
- 宽窗口并排展示，窄窗口整组换行，详情统一使用滚轮浏览，避免横向溢出。

## 首版建议范围

1. 数据读取、模型转换、缓存、失败与空数据处理。
2. 英雄榜及英雄详情摘要。
3. 分稀有度的强化推荐。
4. 装备与召唤师技能推荐。
5. 跟随选人、前进后退、筛选状态与滚动恢复。

强化组合、英雄协同和阵容推演作为后续范围，待数据定义核实后安排。

## 不包含的功能

- 未确认数据支持的标准符文页及技能加点。
- “应用符文页”按钮：海克斯强化不是标准符文页。
- 自动选择游戏内强化、自动执行游戏操作。
- 自动收集或上传用户对局。
- 将来源不存在的数据伪装成当前版本的完整统计。
